INSTRUCTIONS.md — Site Institucional Astute4AI

Objetivo do projeto

Criar um site institucional moderno, profissional e persuasivo para a marca Astute4AI, com foco em apresentar a empresa, seus serviços, projetos de referência e gerar novos contatos comerciais.

O site será hospedado na Vercel e deve ser desenvolvido com uma stack moderna, preferencialmente:

* Next.js
* React
* TypeScript
* Tailwind CSS
* App Router
* Design responsivo
* SEO básico
* Performance otimizada

A proposta principal do site é transmitir que a Astute4AI desenvolve soluções digitais inteligentes, SaaS, automações, agentes de IA, plataformas web e produtos sob medida para negócios que desejam vender mais, operar melhor e inovar com tecnologia.

⸻

Contexto da marca

A Astute4AI é uma marca voltada à criação de soluções digitais com inteligência artificial, automação e desenvolvimento web.

A empresa atua na interseção entre:

* Inteligência Artificial
* SaaS
* Automações de processos
* Sistemas web sob medida
* Aplicações para negócios locais
* Produtos digitais escaláveis
* Experiências digitais para captação de clientes

A comunicação deve passar a ideia de uma empresa moderna, confiável, prática e orientada a resultado.

Evitar linguagem excessivamente técnica. O site deve falar com empresários, empreendedores, donos de pequenos e médios negócios, startups e profissionais que desejam transformar ideias em produtos digitais.

⸻

Astute4AI
